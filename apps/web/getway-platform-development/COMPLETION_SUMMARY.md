## Quick Start

1. Install dependencies
   ```bash
   pnpm install
   ```

2. Run development server
   ```bash
   pnpm dev
   ```

3. Open browser
   ```
   http://localhost:3000
   ```

4. Build for production
   ```bash
   pnpm build
   ```
