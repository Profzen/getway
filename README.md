# GETWAY Monorepo

GETWAY is organized as a monorepo with a clear split between the web experience and the mobile experience.

## Structure
- `apps/web` - web application, built to preview on Vercel and serve as the primary product surface.
- `apps/mobile` - Expo-based mobile application.
- `packages/ui` - shared UI primitives and reusable components.
- `packages/config` - shared configuration and design tokens.

## Visual Direction
- Light mode is the base reference.
- Dark mode is the premium variant.
- The design system must stay coherent across both surfaces.

## Status
The repository is being scaffolded locally. The remote GitHub repository already exists, but the local project structure is being created now.
